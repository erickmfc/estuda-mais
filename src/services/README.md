# Services

Esta pasta reúne as integrações usadas pelo aplicativo:

- `climaService.js`: consulta de localização e previsão do tempo.
- `supabase.js`: cliente de autenticação e sessão.
- `studentDataService.js`: leitura e gravação dos dados do estudante no Supabase.

Nesta aula, os itens ficam apenas na memória enquanto o aplicativo está aberto.
